# Glassy
Add transparency to gnome dock, calendar and other things. Created by google AI with my help.

Install:
1 - Drop the folder inside your $HOME/.themes
2 - Go to extension manager (install if you dont have).
3 - Open the "User Themes" extension (install too, if you dont have).
4 - Select the Glassy theme and be happy.

Ain't upgrading this unless it breaks (maybe). Do whatever you want.
